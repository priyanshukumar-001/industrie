# Industrie Website

## About the Project

**Industrie** is a responsive multi-page website created for an industrial engineering and laboratory solutions company. The project presents the company's services, production process, projects, achievements, team, and blogs in a professional and user-friendly format.

The website is also designed as a practical front-end project. Along with the complete business website, it includes a dedicated resume page for **Priyanshu Kumar**, an AI/ML Engineer.

## Why This Website Was Created

This project was developed to:

- Showcase industrial and laboratory services online.
- Present company information, history, mission, and vision clearly.
- Help potential clients learn about the company's work process and projects.
- Make enquiries and quote requests easy for users.
- Demonstrate a polished, responsive, and modern industrial website design.
- Provide an attractive personal resume and professional portfolio page.

## Pages Included

- **index.html** - Home page with hero content, about, services, projects, counters, testimonials, team, blog, and newsletter sections.
- **about.html** - Company overview, journey, solutions, achievements, team, and testimonials.
- **blog.html** - Industrial articles, categories, recent posts, tags, search, and pagination.
- **contact.html** - Contact information, enquiry form, office locations, map, and FAQs.
- **product-details.html** - Product information, quantity selection, reviews, related products, and cart interaction.
- **resume.html** - Personal resume showing skills, experience, education, projects, achievements, and certifications.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3
- Bootstrap Icons
- Font Awesome
- Google Fonts

## Project Files

- `index.html`, `about.html`, `blog.html`, `contact.html`, `product-details.html`, `resume.html` - Website pages.
- `css/style.css` - Global styles and responsive layouts.
- `js/main.js` - Navigation, counters, filtering, forms, image fallbacks, modals, and footer behavior.

## Main Features

- Responsive design for mobile, tablet, and desktop screens.
- Sticky navigation and back-to-top button.
- Bootstrap carousels, tabs, modals, offcanvas menus, accordions, and toast notifications.
- Animated business counters and project filtering.
- Newsletter, quote, contact, and resume contact forms.
- Related product and blog sections.
- Image fallback handling for unavailable images.

## Purpose

The main purpose of this website is to create a complete digital presence for an industrial engineering company. It helps communicate the company's expertise, build trust with visitors, explain its services, showcase completed work, and provide an easy way for customers to make enquiries.

The resume page additionally demonstrates Priyanshu Kumar's professional profile and technical portfolio.
